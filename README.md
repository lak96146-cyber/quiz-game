# 🧠 QuizVerse

> A modern, interactive quiz game built with HTML, CSS and JavaScript.

QuizVerse is a simple quiz game designed to make answering questions more engaging through a clean interface, countdown timer, streaks, power-ups and instant feedback.

The project was built as a hands-on way to practice JavaScript and create a complete interactive web experience from scratch.

---

## ✨ Features

- 🎯 10 multiple-choice questions
- ⏱️ 15-second timer for every question
- 📊 Live question progress
- 🔥 Streak-based bonus scoring
- ❤️ Lives system
- 💡 Instant answer explanations
- ½️⃣ 50/50 power-up
- ⚡ +10 seconds power-up
- 🏆 Final score & accuracy
- 💾 Personal best saved with Local Storage
- ⌨️ Keyboard controls
- 📱 Responsive design
- ✨ Smooth UI animations

---

## 🎮 How It Works

1. Start the quiz.
2. Read the question and choose an answer.
3. Answer quickly to earn speed points.
4. Keep answering correctly to build your streak.
5. Use power-ups when you need them.
6. Complete all 10 questions.
7. Check your final score and accuracy.
8. Play again and try to beat your personal best.
